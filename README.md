# EIC Club Dashboard

Event-tracking and member-analytics dashboard for a university
**Entrepreneurship & Innovation Cell (EIC)** — a REST API plus a single-page
front end that gives club leads a live view of membership growth, event
attendance and branch participation.

**Stack:** Node.js · Express · vanilla JS/HTML/CSS (no front-end framework) · Chart.js

🔗 **Live demo:** _deployed on Vercel_ — see [Deployment](#deployment)

---

## What it does

- **Members** — list/filter by branch, role, active status; add new members
- **Events** — list/filter by category or date range; add new events
- **Analytics** — overview KPIs, member-growth trend, attendance trend,
  event-category breakdown, branch breakdown

Data is generated by a seeded PRNG on startup (240 members, 28 events spread
over ~2 years) so every run gets realistic, stable numbers with no database
or credentials required. POSTs mutate the in-memory store for the life of
the process.

## API

| Endpoint | Method | Description |
|---|---|---|
| `/api/health` | GET | liveness check |
| `/api/members` | GET | list members, filter by `branch`, `role`, `active` |
| `/api/members` | POST | add a member (`name`, `branch` required) |
| `/api/events` | GET | list events, filter by `category`, `from`, `to` |
| `/api/events/:id` | GET | single event |
| `/api/events` | POST | add an event (`title`, `category`, `date` required) |
| `/api/stats/overview` | GET | headline KPIs |
| `/api/stats/member-growth` | GET | cumulative members by month |
| `/api/stats/attendance-trend` | GET | per-event attendance |
| `/api/stats/event-categories` | GET | events + attendance by category |
| `/api/stats/branch-breakdown` | GET | member count by branch |

## Run it locally

```bash
npm install
npm start                 # serves the API + dashboard at http://localhost:3000
npm run dev                # same, with --watch for auto-reload
npm test                   # runs the API smoke tests (node --test)
```

## Deployment

Configured for zero-config deploy on [Vercel](https://vercel.com):
`vercel.json` rewrites `/api/*` to the serverless entry point
`api/index.js`, which re-exports the Express app; static assets in
`public/` are served directly.

1. Push this repo to GitHub.
2. On Vercel → **New Project** → import this repo → deploy (no env vars needed).

## Project layout

```
src/app.js              Express app factory: middleware, /api mount, static files
src/routes/api.js        REST routes for members / events / stats
src/data/store.js        seeded mock data + analytics helpers (in-memory)
api/index.js              Vercel serverless entry (wraps src/app.js)
public/                   dashboard front end (HTML/CSS/vanilla JS + charts)
test/api.test.js          smoke tests (node --test)
```

## Notes & limitations

- In-memory data store — restarting the process resets any POSTed data;
  there's no database or auth layer, by design, since this is a portfolio
  demo rather than a production club-management system.
- Mock data is generated with a fixed seed, so member/event names are
  synthetic, not real club records.
